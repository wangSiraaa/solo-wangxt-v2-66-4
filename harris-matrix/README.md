# 地层矩阵编辑台（Harris Matrix Workbench）

纯浏览器运行的考古地层矩阵编辑工具：Vue 3 + TypeScript，Graphology 管理有向关系，
Cytoscape.js 绘制矩阵，Dexie(IndexedDB) 本地持久化。**不发生任何网络上传**，现场资料只存于本机浏览器。

## 运行

```bash
npm install
npm run dev       # 开发
npm run build     # 产出静态文件到 dist/，可离线部署
npm test          # 验收与单元测试（vitest + fake-indexeddb + happy-dom）
npm run typecheck
```

## 证据复核闭环（核心工作流）

每条**原始观察**可附**多条证据**：证据含类型（照片/剖面图/田野日记/测绘记录/其他）、
说明、采集日期与**本地附件**（文件内容以字节存入 IndexedDB `attachments` 表，绝不上传）。
每条证据经历三种状态：**待复核 → 已采纳 / 已驳回**，状态由只追加的复核审计链回放得到。

- **有效门槛**：一条观察当且仅当「至少一条证据已采纳」且「没有未解决否决
  （已驳回且之后未再采纳）」时，才进入有效偏序计算。待复核证据不影响矩阵。
- **推断实时重算**：推断关系不再手工登记，而是在无冲突的有效观察 DAG 上实时导出
  传递闭包（距离 ≥2 且无直接观察边的有序对）；采纳/驳回/撤销复核后即刻重算。
- **成环不静默丢弃**：采纳某证据会使关系成环时，**复核决定照样保留**，该观察被
  实时标记为环冲突（画布红边 + 侧栏完整环路径），冲突边不参与偏序；否决环上另一条
  边后冲突自动解除。
- **复核审计**：每次采纳/驳回记录操作者名称、时间、意见、前后状态（`reviews` 表只追加）。
  工具条「撤销最近复核」把最近一条审计标记为已撤销并回滚决定，**历史永不删除**。
- **附件**：可在证据上下载/重新登记；附件 Blob 缺失时，证据与工程照常加载，
  顶部横幅与证据行内显式提示缺失。
- **导出/导入（v2）**：JSON 携带证据、完整审计链、附件 data URL 与偏序闭包；
  重新导入后审计链、附件可用性与偏序计算结果一致（导入时重算可达对比对）。
  v1 旧工程（证据只有 ref/text）在导入或首次打开时自动迁移，并补一条「系统迁移·采纳」审计。

## 数据模型要点

- **身份与位置分离**：层位（`units`）与画布坐标（`positions`）分表存储，拖动/自动排布不影响地层身份。
- **记录分表**：原始观察（`relations` 中 `source=observation`）、证据（`evidences`，按关系归属）、
  复核审计（`reviews`，只追加）、附件二进制（`attachments`）、被撤销判断（`retractions`）。
- **同期关联不是有向边**：`contemporary` 关系只存档、以紫色点线显示，绝不进入有向图与偏序闭包。
- **旧版手填推断**：v1 中手工登记的 `inference` 关系不再参与计算，在侧栏灰显存档；
  所有推断一律由有效观察集实时导出。
- **矩阵简化只隐藏**：简化视图隐藏传递冗余边与推断边，原始记录全部保留。
- **批次撤销**：数据编辑登记为含逆变更的批次（`batches` 表），撤销整批回滚——关系、证据、附件一起恢复；
  复核操作走独立的审计撤销（可回滚决定但不删除历史），两套撤销互不干扰。

## 示例工程

「载入示例」包含：已采纳生效的观察链、**采纳+驳回混合导致不生效**的关系（R4）、
采纳后即**成环冲突**的记录（R10，且其曾被采纳又撤销复核、审计保留）、
**待复核且附件本机缺失**的关系（R11，显式提示但不阻断加载）、
旧版手填推断存档（R5/R8/R12 其中 R12 已撤回）、同期关联（R9）、孤立层位 1018。

## 验收测试

`test/acceptance.test.ts` 逐条对应验收标准：

1. 待复核证据不影响矩阵（边、推断、闭包均为空）；
2. 采纳后生成新传递结论，撤销最近复核后结论消失（审计仍在）；
3. 同一关系多证据混合状态按门槛生效/失效/恢复，并可逐次回滚；
4. 采纳造成环时保留决定并生成冲突（含完整环路径、不入偏序），否决他边后冲突解除；
5. 刷新（重新从 IndexedDB 装载）后审计链、冲突、推断、闭包一致；
6. 导出再导入后审计链、附件可用性与计算结果一致；附件缺失不阻断加载；v1 工程自动迁移。
