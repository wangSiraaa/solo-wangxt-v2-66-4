# 地层矩阵编辑台（Harris Matrix Workbench）

纯浏览器运行的考古地层矩阵编辑工具：Vue 3 + TypeScript，Graphology 管理有向关系，
Cytoscape.js 绘制矩阵，Dexie(IndexedDB) 本地持久化（含附件二进制）。**不发生任何网络上传**，现场资料只存于本机浏览器。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 产出静态文件到 dist/，可离线部署
npm test         # 证据复核闭环验收测试（Node + fake-indexeddb，无需浏览器）
```

## 证据复核闭环（v2）

每条原始观察可附**多条证据**，证据含类型（日记/照片/剖面图/地层卡/其他）、说明、
采集日期与**本地附件元数据**（附件二进制单独存 `attachments` 表，内容仍只在浏览器本地）。

- **三态复核**：待复核 → 已采纳 / 已驳回；驳回即“否决”。
- **生效规则**：只有 **至少一条已采纳且没有未解决驳回** 的关系才进入有效偏序计算；
  待复核证据既不激活也不算否决。
- **推断实时重算**：推断关系不再手工录入，而是有效观察偏序闭包中不由观察直接给出的
  可达对，随证据复核状态实时派生（侧栏展示每条推断的传递路径）。
- **成环不静默丢弃**：采纳一条会造成环的证据时，复核决定与关系全部保留，系统生成
  **冲突**（红边 + 完整环路径），冲突边不进入偏序；驳回证据或撤销复核即可解除。
- **审计链不可删除**：每次复核记录操作者、时间、意见与前后状态（`reviews` 表）。
  “撤销复核”只能撤销该证据最近一条有效决定——做法是把原记录标记 `undone` 并追加一条
  撤销记录，历史完整保留。
- **缺失附件不阻塞**：附件二进制缺失（被清理/导入未携带）时，横幅与证据行显式提示，
  证据元数据、审计链与全部计算照常加载。
- **导出/导入**：JSON 携带偏序闭包、完整审计链与附件（base64 内联，纯本地文件）；
  导入后重算偏序比对，审计链重放后的状态、附件可用性与计算结果一致。v1 工程自动迁移
  （旧的全局证据按关系引用复制为归属证据，状态回到待复核）。

## 数据模型要点

- **身份与位置分离**：层位（`units`）与画布坐标（`positions`）分表存储，拖动/自动排布不影响地层身份。
- **三类记录分开保存**：原始观察（`relations`，证据复核通过才生效）、被撤销判断
  （`retractions` 表，含快照与理由）、复核审计（`reviews` 表，只追加不删除）。
- **同期关联不是有向边**：`contemporary` 关系同样需证据复核通过，但只以紫色虚线显示，
  绝不进入 Graphology 有向图与偏序闭包。
- **矩阵简化只隐藏**：简化视图通过传递约简隐藏冗余边，原始记录全部保留。
- **批次撤销**：关系/证据/附件等变更登记为含逆变更的批次（`batches` 表），撤销整批回滚；
  复核操作不进批次（审计链只追加），通过“撤销最近复核”单独回滚。

## 示例工程

「载入示例」覆盖闭环全部分支：已采纳的正常序列（基槽/灰坑切割、同期关联）、
混合证据关系（采纳 + 未解决驳回 + 待复核，不生效）、纯待复核观察（不影响矩阵）、
**采纳造成环的冲突**（保留决定、红边提示）、已撤回观察，以及一个**声明了附件但二进制
缺失**的证据（顶部横幅显式提示）和一个可正常打开的本地附件。

## 目录

```
src/graph.ts    Graphology 封装：成环拆分、传递约简、偏序闭包、传递推断、分层排布
src/store.ts    状态与业务：证据闸门、复核审计、批次撤销、导入导出、偏序校验
src/db.ts       Dexie/IndexedDB 七张表（v1→v2 自动迁移）
src/sample.ts   示例工程（含全部复核分支）
test/           证据复核闭环验收测试（6 组场景）
src/components/MatrixCanvas.vue  Cytoscape 画布（有效观察/推断/冲突/待复核分样式）
```
